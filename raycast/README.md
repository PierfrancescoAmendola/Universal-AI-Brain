# 🚀 Raycast Extension per Universal AI Brain

Questa cartella contiene gli **Script Commands nativi per Raycast** (macOS) per interagire con il tuo connettoma cognitivo in tempo reale con **zero latenza e zero costi**.

---

## 📦 Comandi Inclusi

1. **🧠 Cerca nel Cervello (`brain_search.py`)**
   - **Scorciatoia consigliata:** `Cmd + Shift + F`
   - Ricerca full-text FTS5 BM25 per parola chiave con visualizzazione Markdown dettagliata.
   - Supporta filtro per emisfero (`LEFT`, `RIGHT` o `ALL`).

2. **➕ Aggiungi al Cervello (`brain_quick_add.py`)**
   - **Scorciatoia consigliata:** `Cmd + Shift + A`
   - Inserimento rapido di nuove idee o regole con auto-classificazione di Emisfero e Macro-Dominio.

3. **📋 Cattura Appunti nel Cervello (`brain_capture_selection.py`)**
   - **Scorciatoia consigliata:** `Cmd + Shift + B`
   - Cattura istantanea del testo copiato negli appunti di sistema (clipboard).

---

## ⚙️ Come Attivare in Raycast (1 Click)

1. Apri **Raycast** (`Option + Space` o `Cmd + Space`).
2. Digita **"Settings"** (o `Cmd + ,`) e vai nella scheda **"Extensions"**.
3. Clicca su **"+"** in basso a sinistra (oppure in alto a destra) e seleziona **"Add Script Directory"**.
4. Seleziona la cartella:
   ```
   /Users/pierfrancesco/Desktop/CervelloArtificiale/raycast
   ```
5. Ora i comandi compariranno istantaneamente in Raycast! Puoi assegnare scorciatoie da tastiera dedicate.
