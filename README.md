## 🌌 Visione & Modello Bi-Emisferico

**Universal AI Brain** è un sistema di memoria cognitiva a lungo termine progettato per dare alle intelligenze artificiali (Claude, Gemini, Antigravity, ChatGPT, Cursor) un substrato persistente, associativo e trans-emisferico:

```
 ┌─────────────────────────────────────────┐       ┌─────────────────────────────────────────┐
 │    EMISFERO SINISTRO (⚡ Logic & Tech)   │       │   EMISFERO DESTRO (🌸 Art & Emotions)   │
 │    Colore: #00D2FF (Ciano / Blu Neon)   │       │   Colore: #FF007F (Magenta / Rosa Neon) │
 ├─────────────────────────────────────────┤       ├─────────────────────────────────────────┤
 │ • ARCHITECTURE                          │       │ • DESIGN_TOKEN                          │
 │ • DATA_STRUCTURE                        │◄═════►│ • COLOR_PALETTE                         │
 │ • ALGORITHM                             │Corpo  │ • UI_COMPONENT                          │
 │ • DEPENDENCY                            │Calloso│ • UX_FLOW                               │
 │ • BUSINESS_LOGIC                        │       │ • BRAND_VOICE                           │
 │ • API_SPEC                              │       │ • CREATIVE_IDEA                         │
 │ • COGNITIVE_RULE                        │       │ • EMOTIONAL_MEMORY                      │
 │ • MENTAL_MODEL                          │       │ • LIFE_LESSON                           │
 │ • AI_REASONING                          │       │ • RELATIONSHIP                          │
 │ • METACOGNITION                         │       │ • PERSONAL_VALUE                        │
 │ • USER_INTENT                           │       │ • CONVERSATION_EPISODE                  │
 └─────────────────────────────────────────┘       └─────────────────────────────────────────┘
```

I due emisferi comunicano attraverso il **Corpo Calloso**, che collega le scelte ingegneristiche e algoritmiche ai valori personali, alle esperienze vissute e ai pattern di design.

## ✨ Funzionalità Chiave

1. **🌳 Motore ad Albero Gerarchico (`層級譜系樹`)**:
   - Abilita il *Semantic Zoom* multilivello (`Radice ➜ Emisferi ➜ Tassonomie ➜ Nodi`).
   - Risparmio dell'80% di token rispetto al dump raw del grafo per gli LLM.
2. **🔍 Motore di Ricerca Ibrido BM25 (GraphRAG)**:
   - Ricerca full-text istantanea (<1ms) con SQLite FTS5 e tokenizzazione Porter Unicode61.
3. **⚡ Cammini Minimi & BFS Bidirezionale**:
   - Traccia percorsi sinaptici minimi tra concetti tecnici ed emotivi che attraversano il Corpo Calloso.
4. **🔌 Server MCP Nativo (`mcp_server.py`)**:
   - Fornisce 7 tool conformi a Model Context Protocol per Claude Desktop, Antigravity e Cursor.
5. **📱 Gateway Telegram Serverless (`@pier_brain_ai_bot`)**:
   - Webhook FastAPI per interrogare il cervello, cercare progetti, vedere i log e salvare nuove idee al volo da smartphone.
6. **💻 Console & Terminale Live**:
   - Ispezione real-time di nodi aggiunti, aggiornamenti SQLite WAL e chiamate API.
7. **🤖 Skill Universale `/brain`**:
   - Installabile globalmente su qualsiasi computer per permettere a qualsiasi assistente AI di consultare e salvare memorie.

## ⚡ Installazione Rapida in 1 Click (Mac / Linux)

Per installare il comando globale `brain`, la skill per gli agenti e la configurazione MCP:

```bash
git clone https://github.com/PierfrancescoAmendola/Universal-AI-Brain.git
cd Universal-AI-Brain
chmod +x install.sh
./install.sh
```

Ora puoi usare il comando da qualsiasi terminale:
```bash
brain stats
brain search flutter
brain tree
brain add "Nuova Idea" "Sintesi del concetto"
brain open
```
