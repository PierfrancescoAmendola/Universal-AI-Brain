# 🌐 Universal AI Brain - Web Clipper (Manifest V3)

Estensione browser leggera, moderna e fluorescente per catturare articoli, documentazione tecnica e spunti di riflessione direttamente nel tuo Connettoma Cognitivo Bi-Emisferico.

---

## 🚀 Installazione su Chrome / Arc / Brave / Edge (30 Secondi)

1. Apri la pagina delle estensioni del browser:
   - Chrome / Brave: `chrome://extensions`
   - Arc: Apri le estensioni dal menu
2. Attiva la levetta in alto a destra: **"Modalità sviluppatore" (Developer mode)**.
3. Clicca sul pulsante in alto a sinistra: **"Carica estensione non pacchettizzata" (Load unpacked)**.
4. Seleziona la cartella:
   ```
   /Users/pierfrancesco/Desktop/CervelloArtificiale/web_clipper
   ```
5. L'icona 🧠 comparirà nella barra del browser, pronta all'uso!
